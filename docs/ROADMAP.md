## Цель

Программа для Windows, которая ограничивает игровое время ребёнка. Альтернатива Time Boss: тот **закрывает все программы на время паузы**, а здесь программы **не закрываются** — только блокируется сеанс или замораживаются процессы.

## Требования пользователя

- **Ребёнок:** 10 лет, своя учётная запись Windows **без прав администратора**.
- **Лимиты:** дневной лимит по категориям программ («Игры», «Учёба», «Видео», «Неизвестное»), у отдельных игр — свой лимит.
- **Перерывы:** правило «N минут → перерыв M минут». Во время перерыва программы не закрываются.
- **Расписание:** разрешённые часы по дням недели.
- **Программы:** разрешённые и запрещённые.
- **Интернет:** браузеры пока полностью запретить. Сам интернет нужен играм и Steam.
- **ИИ:** определять категорию новой программы через ИИ на сервере в локальной сети (Proxmox).

### Срочно, до этапа 2

- #4 — выход и выключение с приостановленной программой закрывают остальные программы ребёнка. Нарушает главное правило.
- #5 — хранимый XSS в таблице Grace Request.
- #18 — без TOTP (по умолчанию) веб-панель работает без входа: ребёнок может сам дать себе бонус или снять лимит. В работе: change `require-admin-sign-in`, PR #21 — веб-панель всегда требует TOTP, настройка только в Parental Control Admin. Осталась проверка на VM.

### Этап 2. Перерывы и запреты

- Перерывы «N минут → M минут» для всего сеанса — сделано (change `add-usage-breaks`, PR #31, спека `openspec/specs/usage-breaks`). На перерыв — `LockSession`, программы остаются открытыми. Предупреждения за 5 и за 1 минуту. Карточка «Pausen» в веб-панели, `/break` в Telegram.
- **После обновления перерывы включены** (45/10, решение D2). Это должно быть в release notes версии.
- Следующее изменение: перерывы для категории (приостановить программы одной категории).
- Запрещённые программы — сделано (change `add-blocked-programs`, PR #33, спека `openspec/specs/blocked-programs`): блок на App Rule, закрытие только **при запуске** (WMI `Win32_ProcessStartTrace` + тик 60 с), уже запущенная программа приостанавливается. 15 браузеров заблокированы по умолчанию, `msedgewebview2.exe` не трогается. Проверено на VM 102 (2026-11-26). Открыто: уведомление в Telegram (#13) и проверка на ПК ребёнка. Решения: `openspec/changes/archive/2026-11-26-add-blocked-programs/design.md`.
- Потом: режим «только разрешённые программы» (allow-list) и распознавание переименованного или портативного браузера (ресурс версии или подпись).
- Связанное: #11 (немецкий по умолчанию), #12 (предупреждения App Limit).

### Этап 4. Сервер и ИИ

- Новая программа → сервер в локальной сети. Метаданные: путь, имя, ProductName/CompanyName/FileDescription, издатель подписи, папка (`steamapps\common`, `Epic Games`), заголовок окна, командная строка, SHA256.
- На сервере: кэш → жёсткие правила → LLM (OpenAI-совместимый endpoint). Ответ — строгий JSON: категория из списка + уверенность.
- Низкая уверенность → запрос родителю в Telegram. Решение родителя важнее ИИ и становится правилом.
- Пока программа не опознана, она в Unknown, время идёт.
- Данные из exe — недоверенные (prompt injection).
- Клиент хранит правила у себя и работает без сервера, статистику досылает.
- Сервер — отдельный LXC на pve2, приложение в `ansible-proxmox`.
